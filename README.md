## 🌟 Overview

**L-Trace** is a zero-trust, cryptographically verified digital evidence bridge designed to solve the critical gaps in how medico-legal evidence moves between healthcare institutions, forensic laboratories, police precincts, and judicial courts.

- **The Problem**: Medico-legal evidence (toxicology reports, SAEKs, post-mortem summaries) currently suffers from paper-based transit delays (14+ days), evidence tampering risks, and legal challenges in court.
- **The Solution**: **L-Trace** — SHA-256 cryptographic chain of custody, QR-based custodian handovers, automated medico-legal certificate creation, and role-governed portals for Doctors, Forensic Scientists, and Police Officers.

This repository serves as an **Interactive B2G & Enterprise Product Marketing Portfolio**, featuring complete deliverables for **Product Marketing Managers (PMM)**, **Account-Based Marketers (ABM)**, and **Content Strategists**.

## 🛠️ Quick Start & Local Setup

```bash
# Clone the repository
git clone git@github.com:gajanand-24/ltrace-health-justice-marketing-project.git

# Navigate into directory
cd ltrace-health-justice-marketing-project

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open `http://localhost:5173` in your browser to view the live interactive application.
